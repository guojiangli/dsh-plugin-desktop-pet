## [0.1.0] - 2026-08-15

### Added

- Draggable desktop pet in the DSH Web shell overlay.
- Browser-local image upload and configuration.
- Settings page under Settings > Plugins > Desktop Pet.
- Current-session running state and `todos` progress display.
- Reduced-motion support and responsive settings layout.
- Reproducible TypeScript/esbuild build, tests, and package verification.
